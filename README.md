To run the system:

step 1: open a terminal and run the respective docker environment command and keep it running.

step 2:reun the respective assigner file with the configurations of llm used described in the yaml files in configs/assignments.(os_only.yaml for using ollama in os env)

OS:

 docker compose -f extra/docker-compose.yml up redis controller os_interaction-std

 python -m src.assigner --config configs/assignments/os_only.yaml

DB:
 
 docker compose -f extra/docker-compose.yml up redis controller dbbench-std

 python -m src.assigner --config configs/assignments/dbbench_only.yaml

ALFWORLD:

 docker compose -f extra/docker-compose.yml up redis controller alfworld-std

 python -m src.assigner --config configs/assignments/alfworld_only.yaml


WEBSHOP:

 docker compose -f extra/docker-compose.yml up redis controller webshop-std

 python -m src.assigner --config configs/assignments/webshop_only.yaml
